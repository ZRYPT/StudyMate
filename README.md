# StudyMate
#### Video Demo: https://youtu.be/Na0Kaai66n4

#### Description:
StudyMate is a command-line study assistant written in Python designed to help students track study tasks, maintain subject vocabulary, take practice quizzes, and monitor academic progress.

#### Project Structure:
- `project.py`: Contains the main application logic, interactive CLI menus, and core utility functions including task tracking, vocabulary searching, quiz evaluating, and progress logging.
- `test_project.py`: Contains automated unit tests written with `pytest` to verify core functions.
- `requirements.txt`: Lists external dependencies required to run the project.

#### Features:
1. **Study Tasks**: Add, view, complete, and delete daily academic study tasks.
2. **Subjects**: Categorize learning items by specific academic subjects.
3. **Vocabulary**: Store, view, search, and delete subject-specific terms with definitions and example sentences.
4. **Quiz Engine**: Create custom multiple-choice questions and attempt quizzes with automatic scoring.
5. **Progress Tracker**: Monitor cumulative stats including active tasks, stored terms, completed quiz attempts, and scores.
